Bundled fonts for the display_font option (licenses in ./licenses).

default   Open Sans (variable, OFL) - stand-in for Discord's gg sans, also used for all body text
sakura    Nothing You Could Do (OFL)
jellybean Comic Relief Bold (OFL)
modern    Outfit Bold (OFL)
medieval  KaTeX Fraktur Bold (OFL)
8bit      Silkscreen (OFL)
vampyre   Gloock (OFL)
emoji     Noto Color Emoji (OFL), used to draw reaction emoji
fallback  DejaVu Sans (Bitstream Vera license)

These are close look-alikes, not Discord's own proprietary font files.
