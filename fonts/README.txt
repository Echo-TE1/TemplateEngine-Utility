Bundled fonts (licenses in ./licenses).

Open Sans (variable, OFL)       card text, regular + italic; stand-in for Discord's gg sans
Noto Sans JP, subset (OFL)      Japanese / CJK text (JIS X 0208 kanji, kana, punctuation)
DejaVu Sans Mono                inline code and code blocks
Noto Color Emoji (OFL)          emoji
DejaVu Sans                     last-resort fallback

These are close look-alikes, not Discord's own proprietary font files.
